# Project guidance

For all work in this repository, follow the [project conventions](project.md).

For audit, refactor, or cleanup requests, also read and follow
[the shared guidelines](audit-refactor.md) before starting.
Apply them within the requested scope; newer user instructions take precedence.
Audits run through the agents in `agents/` (`/audit` for a full run, `/audit <agent>` for one); the guidelines describe the run modes.
